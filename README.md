# Contact Form

An accessible contact form built using HTML only, as part of the [roadmap.sh HTML Projects](https://roadmap.sh/projects/contact-form).

## Technologies

- HTML5

## Project Requirements

- Semantic HTML structure
- Accessible form labels paired with form controls
- Form submission using `POST` method
- Text and email inputs with validation
- Select dropdown with multiple options
- Textarea with minimum length validation
- Radio buttons grouped using `fieldset` and `legend`
- Optional newsletter checkbox
- Browser form validation
- Submit button
